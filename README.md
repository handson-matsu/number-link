# ナンバーリンク

同じ数字を縦横の線でつなぐ、PC・スマートフォン・タブレット向けの静的Webアプリです。
**すべてのペアの接続と、すべてのマスの使用を両方満たした場合のみクリア**です。
斜め移動・線の交差・重複・枝分かれはできません。

## 起動

依存パッケージ・ビルドは不要です。リポジトリのルートで実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

[ローカルで遊ぶ](http://127.0.0.1:8000/)。JSONを取得するため、HTMLファイルを直接開かずサーバーを使用してください。
GitHub Pagesでは、このリポジトリのルートを公開対象に設定します。相対URLだけを使用しています。

## 遊び方

- 数字からマウスまたは指でドラッグし、同じ数字へつなぎます。
- 自分の線を戻ると、その位置まで短くできます。数字から引き直すこともできます。
- 他の線・他の数字へは進めません。盤外へ出ても線は維持されます。終点に到達した瞬間に接続を確定し、その後のpointercancelやキャプチャ喪失では取り消しません。未接続の操作中断は操作前へ戻ります。
- Undoはドラッグ1回単位です。リセットもUndoで戻せます。
- 問題の切り替えでは盤面とUndo履歴を初期化します。クリア記録は残ります。
- ヒントは次の1マスを点線で示します。現在の線が一意解と矛盾する場合は、Undo・リセットを案内します。
- キーボードはTabで数字に移動、EnterまたはSpaceで開始、矢印キーで線を引き、Enterで確定、Escapeで取消です。
- 効果音は初期OFF。ONにした場合、クリア時にWeb Audio APIで短い音を再生します。
- クリア記録と音の設定はlocalStorageに保存。保存不可でもゲームを続行できます。

## 問題と検証

全10問：5×5が3問、7×7が4問、9×9が3問。各サイズ内では探索ノード数を目安に並べています。体感難易度には個人差があります。

- `data/puzzles.json`：盤面サイズ・数字ペアのみ。
- `data/solutions.json`：ヒント用の解答データ。画面には完全な解答を表示しません。静的配信のため、開発者ツールからのデータ閲覧を防ぐものではありません。
- `data/verification.json`：採用時の一意性検証結果。
- `engine.js`：線の操作、盤面の検証、クリア判定、ヒント。
- `app.js`：SVG表示、Pointer Events、Undo、保存、効果音、アクセス記録。

```sh
python3 scripts/verify.py
```

すべてのペアを上下左右に伸ばす完全探索で、全マスを埋める解を最大2つまで数えます。未使用マスの次数とペア間の到達性を使って枝刈りします。探索上限超過の問題は検証成功にしません。全10問で正解がちょうど1つあり、保存された解と一致することを確認します。

ブラウザーで [操作テスト](http://127.0.0.1:8000/tests/browser.html) を開くと、ロジックと実際のアプリのPointerEventハンドラーを自動検証します。テスト用iframeで全10問を解答し、Undo・リセット・切替・ヒント・タッチ取消・390pxレイアウトも確認します。合成イベントではネイティブのポインターキャプチャを取得できないため、このAPIのみスタブ化しています。実機のタッチ感度やOS固有の挙動は実機での追加確認が必要です。

## GASアクセス記録

`config.js` の `gasUrl` に、tangram・hexagon-tilingの公開ソースで確認した共通GAS URLを設定済みです。空文字にすると送信しません。

```js
window.NUMBERLINK_CONFIG = { gasUrl: '設定したGASのURL' };
```

初回表示・再読み込みごとに1回、GETクエリ `app=number-link` を送信します。問題切り替えや操作では送信しません。既存アプリと同じ `method: GET`、`mode: no-cors`、`cache: no-store`、`credentials: omit`、`keepalive: true` を使用し、失敗・不正URL・レスポンスの読取不可でもゲームを停止しません。同期例外・非同期通信失敗のいずれも再送しません。アクセスカウンターの表示はありません。既存GAS側がGETの `app` パラメーターを受け取る必要があります。

## 検証実績

- Python：10問すべて全マス使用の一意解を確認。
- ブラウザー：719アサーション成功（マウス・タッチ種別の合成PointerEvent、全10問のクリア操作を含む）。
- 空白が残る全ペア接続、斜め、重複、他ペアへの侵入、完了線の延伸は拒否。
- 本番GASへ `app=number-link` でGETを1回送信し、HTTP 200・本文 `OK` を確認。保存先シートの行追加は権限がないため未確認。

コミット・プッシュ・公開は行っていません。

## 接続処理とクリア表示の改善

SVGの子要素を再描画する前に、永続する盤面SVGでポインターをキャプチャします。終点到達をUndoの確定境界とし、pointerupの最終座標も処理します。確定後の遅延したpointercancel・lostpointercaptureは無視します。

使用マス数・進捗バーを削除し、盤面の下に3つのルールを常時掲載しています。全マス使用時のみ、盤面の光・バウンド、大きな「クリア！おめでとう！」、次の問題ボタンの強調を表示します。音ON時は短い上昇音を再生します。動きを減らすOS設定ではアニメーションを抑制します。

## アクセス記録のテスト

[専用テスト](http://127.0.0.1:8000/tests/access.html) で初回表示と実際のiframe再読み込みを確認します。成功・Promise拒否・同期例外・未設定・不正URLの各ケースで送信回数を検証します。[操作テスト](http://127.0.0.1:8000/tests/browser.html) はGAS通信だけを失敗させた状態で全10問を解答し、ゲーム操作・クリアで追加送信されないことを確認します。テストではGAS宛てfetchを差し替え、本番記録を増やしません。

照合元：[tangram/access-counter.js](https://github.com/handson-matsu/tangram/blob/main/access-counter.js)、[hexagon-tiling/src/access-counter.js](https://github.com/handson-matsu/hexagon-tiling/blob/main/src/access-counter.js)。送信先URLとGETオプションは両方と一致しています。

専用アクセス記録テストは18項目成功、通信失敗下のゲームテストは719項目成功。実送信の確認は上記の1回のみ行い、再送は行っていません。
